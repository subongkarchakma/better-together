# 🌱 Better Together

Better Together is a social development events platform that connects people through meaningful community activities and encourages positive social change.

### ✨ Features

- Explore upcoming social development events.
- User registration and secure login.
- Create and publish community events.
- View detailed information about events.
- Manage your own created events.
- Join community initiatives and activities.
- Responsive and user-friendly interface.

### 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Node.js
- Express.js
- MongoDB
- Better Auth

### 🎯 Mission

Bringing people together to build stronger communities and create a better future.

**Better Together — Small Actions, Big Changes.**
